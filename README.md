# Workflows

A collection of automation workflows.

## Alfred Workflows

### [Admin Credentials](alfred/admin-credentials)

A snippet-triggered workflow that types common admin credentials into login forms. Useful for local dev environments (WordPress, Laravel, etc.) where you're constantly logging in with the same credentials.

Type `aadmin` anywhere to auto-fill the username, tab to the password field, type the password, and submit.

**[Download Admin-Credentials.alfredworkflow](alfred/Admin-Credentials.alfredworkflow?raw=true)** — double-click to install in Alfred.

During install, Alfred will prompt you to configure the credentials:

- **Email / Username** — defaults to `admin@example.com`
- **Password** — defaults to `password`

You can change these anytime in Alfred's workflow configuration (click `[x]` on the workflow).
