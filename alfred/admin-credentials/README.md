# Admin Credentials

A snippet-triggered Alfred workflow that types common admin credentials into login forms. Useful for local dev environments (WordPress, Laravel, etc.) where you're constantly logging in with the same credentials.

## Install

**[Download Admin-Credentials.alfredworkflow](../../alfred/Admin-Credentials.alfredworkflow?raw=true)** — double-click to install in Alfred.

## Usage

Type `aadmin` anywhere to auto-fill the username, tab to the password field, type the password, and submit.

## Configuration

During install, Alfred will prompt you to configure:

- **Email / Username** — defaults to `admin@example.com`
- **Password** — defaults to `password`

You can change these anytime via Alfred's workflow configuration (`[x]` button).
